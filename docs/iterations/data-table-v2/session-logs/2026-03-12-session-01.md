## Decisions Made

- one schema builder:
  - `defineTableSchema(...)`
- runtime primitive:
  - `useTable(schema)`
- `DataList` supports either `schema` or `table`
- unified source model using:
  - `mode: 'client' | 'remote'`
  - `loader` xor `query`
- `client` mode uses plain array contract and no serializer
- `remote` mode uses `{ rows, rowCount }` by default
- serializer supports:
  - `toRequest`
  - `fromResponse`
  - global registry keys
- filters are top-level:
  - `search`
  - `static`
  - `dynamic`
- columns use builder callback API with:
  - `field`
  - `composite`
  - `display`
- context/pageContext retained with same lifecycle role as V1
- toolbar/search/filter/header/footer direction substantially defined
